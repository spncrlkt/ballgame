# 2v2 Update - Planning & Notes

*This document consolidates all information about the 2v2 gameplay system.*

---

## Current State

The game now has **full 2v2 support** with 4 characters (2 per team).

**What exists:**
- Team system (`Team::Left`, `Team::Right`)
- 2 baskets (left and right)
- 4 character spawns using `CharacterId` (L0, L1, R0, R1)
- AI can control any or all characters
- Observer mode (all characters AI-controlled)
- Human can cycle control between characters with Q/LB

**Character Spawn Positions:**
- L0 (left inner): x=-300, y=ARENA_FLOOR_Y + 200
- L1 (left outer): x=-500, y=ARENA_FLOOR_Y + 300 (100px higher than inner)
- R0 (right inner): x=+300, y=ARENA_FLOOR_Y + 200
- R1 (right outer): x=+500, y=ARENA_FLOOR_Y + 300 (100px higher than inner)

Outer characters spawn 100px higher to create visual distinction at match start.

**Still TODO for multiplayer:**
- Local multiplayer input mapping (4 controllers or keyboard splits)
- Netcode for online play
- Team coordination AI improvements

## Architecture

### Entity Structure

- 4 `Player` entities with `Character(CharacterId)` component
- `CharacterId` enum: `L0`, `L1`, `R0`, `R1`
- Each has `Team`, `InputState`, `AiState`
- Human controls one character (switchable with Q/LB)
- AI controls all others

### Input Mapping (Future)

**Options for local multiplayer:**

| Mode | P1 | P2 | P3 | P4 |
|------|----|----|----|----|
| 4 controllers | Pad 0 | Pad 1 | Pad 2 | Pad 3 |
| 2 controllers + keyboard | Pad 0 | Pad 1 | WASD | Arrows |
| Keyboard only | WASD | IJKL | Arrows | Numpad |

### AI Considerations

**Current team coordination:**
- Basic goal system (GetBall, ShootBall, etc.)
- Per-character AI profiles

**Potential improvements:**
- Don't both chase ball simultaneously
- One attack, one defend roles
- Passing between teammates
- Coordinated steal attempts

### Netcode (Future)

Options to research:
- Rollback netcode (fighting game style)
- Lockstep (deterministic)
- Client-server with prediction
